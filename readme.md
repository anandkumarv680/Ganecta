# Ganecta 🚀

**Connect. Build. Grow.**

Ganecta is a developer-focused social platform where developers can connect, share knowledge, participate in coding challenges, and grow together.

## ✨ Features

- 📝 Create, like, and comment on posts.
- 👥 Follow and explore developer profiles.
- 🔍 Search for developers.
- 🏆 Create and join coding challenges.
- 📊 Track daily challenge progress.
- 🎖️ Earn XP, badges, and compete on leaderboards.
- 💬 Real-time chat using Socket.IO.
- 🔔 Real-time notifications.
- 📱 Responsive design for desktop and mobile.

## 🛠️ Tech Stack

| Category | Technologies |
|---|---|
| Frontend | React, TypeScript, Vite |
| Styling | Tailwind CSS |
| Backend | Node.js, Express.js |
| Database | MongoDB, Mongoose |
| Authentication | JWT |
| Real-time | Socket.IO |
| Deployment | Vercel, Render, MongoDB Atlas |

## 🚀 Getting Started

**1. Clone the repository**

```bash
git clone https://github.com/anandkumarv680/Ganecta.git
cd Ganecta
```

**2. Install backend dependencies**

```bash
cd server
npm install
```

Configure the backend `.env` file with your MongoDB URI, JWT secret, port, and client URL.

**3. Install frontend dependencies**

```bash
cd ../client
npm install
```

Configure the frontend `.env` file:

```env
VITE_API_URL=http://localhost:5000
```

**4. Run the application**

Start the backend and frontend using their respective development scripts.
